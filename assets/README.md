# assets/

Static assets for documentation and presentation.

---

## Intended Contents

| Asset Type | Description |
|---|---|
| Architecture diagrams | Pipeline flow diagrams, system design visuals |
| Performance graphs | Score distributions, ranking comparison charts |
| Screenshots | Streamlit UI screenshots for README embeds |
| README images | Any images embedded in the top-level README |

---

## Adding Assets

Place any images, SVGs, or diagrams here and reference them from the README:

```markdown
![Architecture Diagram](assets/architecture.png)
```
